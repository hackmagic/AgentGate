# 术语表

中文 | [English](/en/glossary)

项目专有名词的权威释义。**所有页面与所有翻译都使用这些写法。** 当两个词在这里可能指同一件事时，
其中一个是错的。

标注*不翻译*的词是契约词汇：它们出现在代码、产物文本与审计记录里，在散文中翻译它们会破坏对应关系。

## 核心概念

| 术语 | 定义 | 翻译 |
| --- | --- | --- |
| 边界策略（Boundary policy） | 声明 Agent 何时可以操作用户机器的 YAML 文件。创作的基本单位。 | 边界策略 |
| 策略包（Policy pack） | 一组相关策略加一个 `pack.yaml` 清单组成的目录。 | 策略包 |
| 决策（Decision） | 求值一个事件的结果：`suggest`、`require_approval`、`suppress` 或 `allow`。 | 决策 |
| 信号（Signal） | 决策交给具现层的载荷。承载意图与呈现契约，从不承载动作命令。 | 信号 |
| 回执（Response） | 用户对信号的回答：`approve`、`dismiss` 或 `mute_1h`。 | 回执 |
| 事件（Event） | 适配器产出、由引擎消费的规范化观测。 | 事件 |
| 审计记录（Audit record） | 一行与内容无关的记录，记录决策与回执。九个字段，固定。 | 审计记录 |
| 发现项（Finding） | 派生出的「有问题」陈述。仅建议性质，从不改变退出码。 | 发现项 |
| 修订建议（Suggestion） | 派生出的、可证伪的具体策略改动方案。 | 修订建议 |

## 架构

| 术语 | 定义 | 翻译 |
| --- | --- | --- |
| 纯核心（Pure core） | 做决策的层：解析、求值、信号、静音、生命周期。不做 I/O，不读系统时钟。 | 纯核心 |
| 组合层（Composition layer） | 做编排的层：中间件链、在途收件箱、审计写入。 | 组合层 |
| 表面层（Surface） | 做呈现或编译的层：宠物桥、MCP、编译器、CLI。 | 表面层 |
| 事件适配层（Event adapter） | 把外部观测转成规范事件的层。纯翻译，不含策略逻辑。 | 事件适配层 |
| 中间件链（Middleware chain） | 一次求值依次经过的有序阶段。注册顺序即语义。 | 中间件链 |
| 阶段（Stage） | 链条中一个可替换的步骤（`throttle`、`inbox`、`audit`）。 | 阶段 |

## 生命周期

| 术语 | 定义 | 翻译 |
| --- | --- | --- |
| 生命周期（Lifecycle） | 策略当前所处的状态，从审计日志投影而来。绝不使用第二份状态文件。 | 生命周期 |
| 投影（Projection） | 读取时从审计日志算出的值，自身不存任何状态。 | 投影 |
| 有界静音（Bounded mute） | 带到期时间的静默（`mute_1h`）。由时钟自行结束，无需新的审计行。 | 有界静音 |
| 无界静音（Unbounded mute） | 直到显式解除为止的静默，由连续否决触发。 | 无界静音 |
| 归档（Archive） | 操作者对策略的退役。显式输入，从不推断。 | 归档 |

## 编译器

| 术语 | 定义 | 翻译 |
| --- | --- | --- |
| 编译目标（Compile target） | 一种输出形态：`agents`、`skill` 或 `mcp`。 | 编译目标 |
| 源哈希（Source hash） | 有序策略集的 `sha256`。同一输入在所有目标中相同。 | 源哈希 |
| 格式版本（Format version） | 渲染契约版本，与引擎版本解耦。 | 格式版本 |
| 一致性（Parity） | 「各目标描述同一份策略集」这一主张，用两种方式检查：身份与保真。 | 一致性 |
| 保真（Fidelity） | 从产物文本读回的事实与源策略相符。 | 保真 |

## 不翻译的词

这些是标识符。在任何语言里都保持原样，代码块内外一致。`GateSignal`、`require_approval`、
`action_id`、`AGENTS.md`、`SKILL.md`、`mcp.json`、`AuditRecord`、`AgentGate`、`OpenPets`、
`ActivityWatch`。

## 写作约定

| 约定 | 规则 |
| --- | --- |
| 「引擎」 | 永远指 AgentGate 引擎。指引擎时不要写成「系统」。 |
| 「用户」 | 策略所编码其边界的这个人。不要写成「操作者」——那是负责归档的人。 |
| 「必须」/「绝不」 | 只用于由测试强制的契约陈述。其他情况用「应当」。 |
| 标题大小写 | 除专有名词外一律使用句中大写。 |

## 新增术语

1. 先加到本页对应章节，并写明它的英文写法。
2. 再在需要它的页面里使用。
3. 最后同步到其他语种的术语表。

不允许先在翻译版里加术语：英文术语表是源。
